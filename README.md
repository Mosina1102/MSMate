## 它是什么

MSMate 是装在你 Windows 电脑上的一个软件。它最特别的地方：**你用说话的方式告诉它要干什么，它替你在电脑上动手完成。**

- “帮我把这份 PDF 扫描件转成能编辑的 Word” ——它自己去转图、认字、排版、生成文档
- “领导发来的 PPT 要改三处数字” ——它只改那三处，版式一个像素不动
- “桌面太乱了” ——它先截屏看看现状，再按类型帮你归档，每一步都能撤销
- “帮我查查这五款笔记本哪个值” ——它自己上网搜、读评测，最后给你一张对比表

不用学命令行，不用写提示词，**像跟同事交代工作一样说人话就行。**

## 打工人的活，它都能干

### 📝 写东西
- Word 生成、修改、排版，页眉页脚目录自动处理
- **毕业论文/公文排版闭环**：学校的格式模板发给它 → 套用 → 逐节检查 → 修分页——格式不过关重来的噩梦，到此为止
- 日报周报、工作总结、会议纪要，说个大概它成文

### 📊 做表格和 PPT
- Excel 建表、改数据、写公式、一键美化（现代/经典/政务风格都有）
- PPT 自动排版，18 套配色 4 种风格；**领导发来的 PPT 只改三处？改字不动版式**
- 数据表格 → 自动画图表 → 出图文报告

### 📄 跟文件较劲的活
- PDF 扫描件 → 逐页转图 → 认字 → 汇总成 Word（纸质文件电子化的完整链路）
- 压缩包全家桶（zip/rar/7z，带密码的也行）
- 格式互转、批量改名、按规则归档——**每一步操作前自动备份，改砸了一键还原**

### 🌐 找资料和搬东西
- 四个搜索引擎一起查、网页正文抓取、图片批量下载
- “对比 5 款 NAS 的参数” ——它派几个助手分头去查，汇总成对比表
- GitHub 上找现成轮子：搜仓库、读说明、看源码，给你选型结论
- **要登录的网站也能看**：受控浏览器登录一次（账号池加密记住密码，验证码你来点），之后内容长期可读
- **两台电脑互传**：同一 WiFi 自动发现、断点续传、还能语音对讲

### 🎨 顺手就能干的创作
- 生图（支持参考图改图）、生短视频、2D CAD 零件图（CAD 软件直接打开）
- **海报和小红书封面**：HTML 排版渲染成图——文字是真的文字，永不吃中文乱码（A4 海报/小红书/公众号封面多尺寸预设）
- 录一段你的声音 → 克隆成专属音色 → 让文档用你的声音“读”出来
- **文字 PV 工坊**：歌词自动打轴（三路音源校验）→ 762 个文字部件 12 种风格动效 → 全自动导出；专业动效还有 Remotion 引擎（用 React 写视频）
- 剧本分镜、3D 资产与音效、Unity 游戏素材——创作工坊的手册体系里都有对应章

### 🖥 它怎么操作你的电脑
截屏看现状、打开文件、点按钮、填表单——后台完成，**不抢你的鼠标键盘**。两条技术路线：受控浏览器页签（**4 个页签独立记忆登录态**，A 平台主号 B 平台小号并行不串）+ Windows 原生控件与 COM 操控（Word/Excel/WPS 深度联动，连下拉框和系统弹窗都自动处理）。电脑上的活，它按你说的顺序来，**每 20 步自动存档任务进度，中断了也知道干到哪**。

### 📱 装好之后你会发现的
- **云同步**：设置、会话、工作台跨设备同步，换电脑即迁
- **自动更新**：检查新版本一键升级，装完告诉你“更新了什么”
- **截图标注**：Ctrl+Shift+A 全局快捷键框选截图，标注完直接丢进对话
- **四套主题**：执事风/经典白/莫西猫耳·淡紫/深色，背景（图片/GIF/视频）和透明度模糊随你搭
- **莫西桌宠**：猫耳管家常驻桌面，随任务状态变表情
- **应用内反馈**：问题直达开发者（实时通知），不用翻评论区

## 安全放心（打工人最关心的事）

- **改之前先备份**：删除、覆盖、移动，全部自动快照，一键还原
- **危险操作先问你**：删文件、运行程序，弹卡片让你确认，它不偷偷干
- **C 盘保护**：系统盘（除桌面）硬性拦截，想误删都删不了
- **积分花在哪看得见**：每次 AI 回复标注消耗，余额常驻，每日签到白嫖

## 它是怎么实现的（给开发者）

代码全在仓库里，这里把几条主干亮出来，每条都对应真实文件：

- **AI 主循环**（`ai/agent.js`）：`classifyAutoTask` 四档判定（闲聊/常规/代码/复杂）→ `AUTO_MAINS` 映射模型（规划用旗舰、执行用便宜 MoE，"高规低干"）→ 上下文用到 80% 自动压缩成交接摘要，被压缩的原文进召回库（`ai/chat-recall.js`，语义向量+关键词双轨检索）——长任务不丢记忆，想找回随时搜
- **工具注册表**（`ai/tools.js`）：92 个工具统一在 `TOOL_DEFS` 定义，`name/params/desc/manual` 四件套——`manual` 字段直连 `ai/manuals/` 的深度手册，工具怎么用，AI 按需自己读（25 册，带防循环读判重）
- **安全三闸**（`ai/snapshots.js` + `tools.js`）：删除/覆盖前自动快照（`backupLocal` 写 `meta.json`，`restore` 一键还原，恢复前当前内容也再备份一层）；`structDocWriteBlock` 守卫拦住 `write_file` 直接毁掉 office 文件的 zip 结构；`classify` 分级标记 `destructive/forceApproval`，危险操作必弹审批卡片
- **论文流水线**（`ai/office.js`）：`read_paper_spec` 把学校模板蒸馏成格式规范书 → `apply_word_template` 嫁接内容 → `check_paper_format` 逐项体检产出 issue 清单 → `fix_paper_paging` 修分页——"套模板后必验"是硬关卡，不交付坏件
- **互传协议栈**（`server/`）：UDP 子网定向广播自动发现（`udpDiscovery.js`）→ TCPAgent 粘包解析 + 文件传输状态机六事件（`tcpAgent.js`）→ 互联网桥接走 TLS + 自签证书 TOFU 指纹校验（`netRelay.js`）→ IPv6 邀请串 `MS6.base64url`（`ipv6Invite.js`）——四条通道独立实现，不依赖第三方传输库
- **桌面控制**（`ai/desktop-control.js`）：常驻 PowerShell 子进程 + stdin/stdout JSON 协议，`user32.dll` 直调 `SetCursorPos`/`SendInput`，进程崩溃自动重启——后台操作不抢鼠标键盘
- **质量门**：`test/` 探针逐功能断言 + 冒烟全量回归，1350+ 项断言全绿才发版

外加几个较真的细节：账号池密码走 Electron safeStorage/DPAPI 加密、拒绝明文落盘；网页抓取遇到反爬不硬闯——等 `cf_clearance` 自动过；模拟打字每 120 字符分批防丢字；数据同步白名单过滤防路径穿越。

## 诚实的边界

不藏着，这些它现在做不到：

- 无头快速抓取只抓公开页；要登录的网站请走受控浏览器（账号池记住密码，登录一次长期可读）
- “每天早上自动做日报”这类定时任务还不行，得你来喊它
- 互联网传文件每天 2GB 额度（局域网内随便传，不限制）
- 生视频一条要 2-10 分钟，不能批量
- 微信聊天记录提取插件已在仓库（等微信生态稳定后启用）

完整能力清单见 [CAPABILITIES.md](CAPABILITIES.md)——92 个工具逐个实证过，文档里写的，代码里都有。

## 一个真实的故事：她宁可不交差，也不编数据

有次让 AI 写一组实验数据。换成别的 agent，大概率直接编一张看起来合理的表——反正用户看不出真假。

MSMate 的做法是：**先写了一个完整的测试程序，然后一条一条跑、一条一条记录**，把真实测出来的结果填进去。跑测试烧的 token 比直接编数据贵了不知道多少倍——但那份数据是真的，敢放在任何人面前复查。

这不是偶然，是写进她骨头里的规矩：子 Agent 查不到的维度，**如实标注“没查到”，禁止编造**；文档里的每个功能必须对应源码（“未落盘的不写”）；1350+ 项断言全绿才发版。

**宁可烧钱，不可烧信誉。**

## 谁适合用

- **适合**：每天跟 Word/Excel/PPT 打交道的上班族；要排版论文的学生；觉得电脑操作繁琐的所有人；两台电脑之间倒文件的任何人
- **暂时不适合**：想要“完全无人值守自动化”的极客（定时任务还没做）；需要深度 Adobe 系列联动的专业剪辑师（在路线图里）
