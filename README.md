## 它是什么

MSMate 是装在你 Windows 电脑上的一个软件。它最特别的地方：**你用说话的方式告诉它要干什么，它替你在电脑上动手完成。**

- “帮我把这份 PDF 扫描件转成能编辑的 Word” ——它自己去转图、认字、排版、生成文档
- “领导发来的 PPT 要改三处数字” ——它只改那三处，版式一个像素不动
- “桌面太乱了” ——它先截屏看看现状，再按类型帮你归档，每一步都能撤销
- “帮我查查这五款笔记本哪个值” ——它自己上网搜、读评测，最后给你一张对比表

不用学命令行，不用写提示词，**像跟同事交代工作一样说人话就行。**

## 打工人的活，它都能干

### 📝 写东西
- Word 生成、修改、排版，页眉页脚目录自动处理
- **毕业论文/公文排版闭环**：学校的格式模板发给它 → 套用 → 逐节检查 → 修分页——格式不过关重来的噩梦，到此为止
- 日报周报、工作总结、会议纪要，说个大概它成文

### 📊 做表格和 PPT
- Excel 建表、改数据、写公式、一键美化（现代/经典/政务风格都有）
- PPT 自动排版，18 套配色 4 种风格；**领导发来的 PPT 只改三处？改字不动版式**
- 数据表格 → 自动画图表 → 出图文报告

### 📄 跟文件较劲的活
- PDF 扫描件 → 逐页转图 → 认字 → 汇总成 Word（纸质文件电子化的完整链路）
- 压缩包全家桶（zip/rar/7z，带密码的也行）
- 格式互转、批量改名、按规则归档——**每一步操作前自动备份，改砸了一键还原**

### 🌐 找资料和搬东西
- 四个搜索引擎一起查、网页正文抓取、图片批量下载
- “对比 5 款 NAS 的参数” ——它派几个助手分头去查，汇总成对比表
- GitHub 上找现成轮子：搜仓库、读说明、看源码，给你选型结论
- **两台电脑互传**：同一 WiFi 自动发现、断点续传、还能语音对讲

### 🎨 顺手就能干的创作
- 生图（支持参考图改图）、生短视频、2D CAD 零件图（CAD 软件直接打开）
- 录一段你的声音 → 克隆成专属音色 → 让文档用你的声音“读”出来
- 文字动起来做 PV——歌词自动打轴那种

### 🖥 它怎么操作你的电脑
截屏看现状、打开文件、点按钮、填表单——后台完成，**不抢你的鼠标键盘**。电脑上的活，它按你说的顺序来。

## 安全放心（打工人最关心的事）

- **改之前先备份**：删除、覆盖、移动，全部自动快照，一键还原
- **危险操作先问你**：删文件、运行程序，弹卡片让你确认，它不偷偷干
- **C 盘保护**：系统盘（除桌面）硬性拦截，想误删都删不了
- **积分花在哪看得见**：每次 AI 回复标注消耗，余额常驻，每日签到白嫖

## 三分钟上手

1. 从 [Releases](../../releases) 下载安装包，一路下一步
2. 邮箱注册登录（密码全程加密传输）
3. 直接说人话交代任务——**内置模型开箱即用，不用配置任何东西**；懂行的也可以填自己的 API Key，走自己额度零抽成

## 诚实的边界

不藏着，这些它现在做不到：

- 需要登录才能看的网页内容，它抓不到（只抓公开页）
- “每天早上自动做日报”这类定时任务还不行，得你来喊它
- 互联网传文件每天 2GB 额度（局域网内随便传，不限制）
- 生视频一条要 2-10 分钟，不能批量

完整能力清单见 [CAPABILITIES.md](CAPABILITIES.md)——92 个工具逐个实证过，文档里写的，代码里都有。

## 谁适合用

- **适合**：每天跟 Word/Excel/PPT 打交道的上班族；要排版论文的学生；觉得电脑操作繁琐的所有人；两台电脑之间倒文件的任何人
- **暂时不适合**：想要“完全无人值守自动化”的极客（定时任务还没做）；需要深度 Adobe 系列联动的专业剪辑师（在路线图里）

## 质量这件事

92 个工具，每一个都有对应的自动化检查，1350+ 项断言全绿才发版。文档里写的每个功能，代码里都有——**“未落盘的不写”是这个项目定文档的铁律。**
