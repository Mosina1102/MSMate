## 它是什么

MSMate 是一个 Windows 桌面应用（Electron）：把**局域网互传**和**AI 电脑操作**装进同一个壳里。

- **互传**——同一 WiFi 下设备 3 秒自动发现，双面板像操作本地一样跨机浏览，断点续传，还有两台电脑的语音对讲
- **AI 助手**——92 个工具、80 册深度手册：文件操作、网页抓取、Word/Excel/PPT/PDF 全套、生图生视频、CAD 出图、声音克隆、受控浏览器
- **内置模型，开箱即用**——不填 API Key 也能用（积分制，签到白嫖）；填自己的 Key 则全免费
- **莫西桌宠**——猫耳管家常驻桌面，随任务状态变表情

一句话：**你说"帮我把这份扫描件转成 Word 排好版"，它自己去截图、OCR、排版、交付，每一步你看得见。**

## 为什么存在

市面上 AI 工具产品有两种通病：要么是只能聊天的壳，要么是能力黑箱——你能用，但不知道它对你电脑做了什么、收的钱花在哪。

MSMate 的答案是把三样东西全透明：

1. **能力透明**：92 个工具逐一实证、写成能力清单（见 [CAPABILITIES.md](CAPABILITIES.md)），"未落盘的不写"——文档里每个功能都对应源码里的实现，没有 PPT 功能。
2. **行为透明**：AI 对电脑的每个危险操作（删除/覆盖/移动/exe）弹审批卡片人工确认；删除覆盖前自动快照，改砸了一键还原；C 盘（除桌面）硬拦截。
3. **成本透明**：每次 AI 回复标注积分消耗，余额常驻；系统层面做了大量省钱设计——便宜模型跑腿、旗舰模型只做规划（"高规低干"）、重复搜索和网页抓取自动走缓存、长前缀对齐上游缓存价。

还有一条原则性的立场：**AI 对验证码和人机验证只做辅助闭环，不做自动绕过**——不自动拖滑块、不接打码平台。工具要有能力边界，这条边界不能碰。

### 几个真实工作流

- **论文排版闭环**：学校模板 + 论文 → 读规范蒸馏 → 套模板 → 逐节体检 → 分页修复——格式不过关重来的噩梦终结者
- **改代码不碰坏文件**：搜代码定位 → 整块替换 → 跑测试 → 改砸了快照一键回滚
- **多线并行调研**："对比 5 款 NAS" → 派 4 个子 Agent 各查各的 → 主 Agent 汇总对比表
- **扫描件转电子档**：PDF 逐页转图 → 逐张 OCR → 汇总成 Word
- **跨电脑搬运**："下载这个安装包直接传到我朋友电脑" → 下载到本机 → 跨设备直传

## 快速开始

1. 从 [Releases](../../releases) 下载安装包（NSIS 安装器，一路下一步）
2. 邮箱注册登录（密码全程 RSA 加密传输）
3. 直接开聊，或者把文件拖进互传面板

- **内置模型**：开箱即用，积分制（每日签到送 50）
- **自带 Key**：设置里填任意 OpenAI 兼容服务商的 Key，走自己额度，零抽成

## 质量文化：探针与冒烟

这个项目有个习惯：**每个功能配一个探针测试**。断言体系 1350+ 项全绿才发版——工具清单计数、边界行为、真机跑通（不是 mock）。某个 bug 修复时如果顺手发现另一个旧探针断言过时，会连着一起修。"修 A 顺手修 B"不是口号，是发版纪律。

## 诚实的边界

不藏着，当前做不到的：

- 不操作浏览器登录态（要登录的网站内容抓不到，只抓公开页）
- 不实时监听系统事件（"每天自动"类需求需要你来喊它，无定时器）
- 互联网大文件传输受 2GB/日额度与服务器带宽限制（局域网直连无限制）
- 生视频 2-10 分钟/条，不能批量；生图 45 积分/张
- After Effects 深度自动化在路线图中，尚未接入

完整能力清单见 [CAPABILITIES.md](CAPABILITIES.md)（全部基于源码实证，未落盘的不写）。
