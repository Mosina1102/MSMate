# 表格工具手册

> 手册版本随应用发布。经验条目以本册为准，禁止编造"第N条"不存在的规则。

## 何时读我

要创建/读取/修改/美化 Excel（.xlsx），或操作 Word 里的表格（增删改/排版/分页修复）时先读本册。

## 工具详解

### create_table

**params**: path(xlsx完整路径), headers(表头数组)+rows(二维数组)，或 content(markdown表格文本)，或 sheets(多工作表对象 {表名: markdown 或 {headers,rows,statusMap}}), merges(可选,合并单元格范围数组如 ["A1:P1","A2:A4"]——大标题行/区块合并用它), styles(可选,范围样式数组 [{range:"B2:B10", bold, italic, font, size, color:"FF0000", bg:"FFF2CC", numFmt:"0.0%", align:"center", valign:"top", wrap:true(长文本自动换行), rowHeight:28(行高磅)}]), statusMap(可选,状态条件配色 {"状态列名":{"已结款":"ok","未结款":"bad","待定":"warn","跟进中":"info"}}——值命中整格上色绿/红/黄/蓝), theme(可选,配色:modern(默认,深蓝表头白字+斑马纹)/classic(浅蓝表头)/gov(红棕公文表)), target(可选)

**desc**: 创建 Excel 表格(.xlsx)，自动美化（表头加粗底色/自动列宽/冻结首行/边框/斑马纹/日期列自动 yyyy-mm-dd 格式）。单元格值以 = 开头会写成公式（如 "=SUM(B2:B10)"）。三种传参任选：headers+rows / content:"| 姓名 | 数量 |\n| 苹果 | 3 |" / sheets:{"汇总":"|..|..|","明细":{headers,rows}}。**状态列（已结/未结、完成/进行中、是/否）务必配 statusMap 自动上色**——ok绿/bad红/warn黄/info蓝，这是人工精修表的灵魂；**备注/说明列长文本配 styles 里 wrap:true 自动换行**，大标题行用 merges:["A1:P1"] + styles 行高加粗居中；精细样式用 styles：百分比/货币等数字格式配 numFmt，字体颜色底色对齐行高都可指定

### read_table

**params**: path(xlsx完整路径), sheet(可选,工作表名,默认第一个), target(可选)

**desc**: 读取 Excel 表格(.xlsx)内容，返回二维数组；多工作表文件会提示全部表名

### append_table_rows

**params**: path(xlsx完整路径), rows(要追加的数据行二维数组), sheet(可选,工作表名), target(可选)

**desc**: 向已有 Excel 表格末尾追加数据行（自动备份；值支持 "=公式"）

### modify_table

**params**: path(xlsx完整路径), cell(单元格引用如 B2)+value(新值,数字/文本/"=公式")，或 cells(批量修改:{"B2":"新值","C3":"=SUM(B2:B3)"} 或 [{cell:"B2",value:"新值"}]), sheet(可选,工作表名), target(可选)

**desc**: 修改 Excel 表格单元格的值（自动备份）；value 以 = 开头写成公式，如 "=SUM(B2:B10)"；改多个格子用 cells 一次批量改：{"B2": 5, "C2": "=B2*2"}

### format_table

**params**: path(xlsx完整路径), theme(可选,配色:modern(默认,深蓝表头白字+斑马纹)/classic(浅蓝表头)/gov(红棕公文表)), target(可选)

**desc**: 美化已有 Excel 表格的格式：主题化表头、自动列宽、冻结首行、细边框（首行视为表头，自动备份）

### read_word_tables

**params**: path(docx完整路径), target(可选)

**desc**: 列出 Word 文档里所有表格（行×列+前两行内容预览）。改表格前先看清单定位是第几个表

### format_word_table

**params**: path(docx完整路径), index(第几个表格,1起)/near(附近文字), style(可选:threeline三线表/grid全边框/zebra斑马/light公文浅色/none无框线), colWidths(列宽数组cm), eastAsiaFont/font/sizePt/align/vAlign(可选,全表), headerFill/headerColor/headerBold/zebraFill/borderSize/borderColor(可选,覆盖), colAligns/colBold/colSizePt/colColors/colEastAsiaFont/colFont(可选,按列覆盖数组), headerRows(表头行数,默认1), keepWithPrev(bool,表前段落与表格同页), widthPct(可选,表宽百分比), target(可选)

**desc**: Word 表格排版（内容不动只改格式）：五预设风格 + 按列参数（语义驱动："金额列右对齐"传 colAligns:["center","right"] 一步到位）。改完可用 read_word_tables 复查

### add_word_table

**params**: path(docx完整路径), rows(二维数组,第一行为表头), colWidths(可选,列宽cm数组), afterText(可选,插到该段文字之后,默认末尾), theme(可选,主题同create_word), eastAsiaFont/font/sizePt(可选), target(可选)

**desc**: 在 Word 文档里插入表格（样式体系同 create_word 的 markdown 表格），afterText 定位段后插入。格式不满意可接着 format_word_table

### edit_word_table

**params**: path(docx完整路径), index(第几个表格,1起)/near(附近文字), ops(操作数组)

**desc**: Word 表格内容级操作。ops 支持：{op:"setCell",row,col,text}（text 支持 \n 换行；或富文本 {paras:[{text,bold,align,color,sizePt,eastAsiaFont}]} 多段异格式）、{op:"insertRow",at,cells:[...]}、{op:"deleteRow",at}、{op:"insertCol",at}、{op:"deleteCol",at}、{op:"mergeCells",r1,c1,r2,c2}（横/纵合并）、{op:"diagHeader",row,col,lines:["右上文字","左下文字"]}（斜线表头：单元格加对角斜线+文字右上/左下错位，适合"项目\季度"这类表头）、{op:"deleteTable"}。含合并单元格的整列插删会明确报错。写操作自动快照可还原

### fix_paper_paging

**params**: path(docx完整路径), target(可选)

**desc**: 全文分页修复：所有表格的表前段落补 keepNext（表标题不与表格被分页拆开）、表首行补跨页重复表头（tblHeader）——长表格跨页时每页自动带表头。表格多/表格长的文档建议修完格式后跑一次

## 本册经验（原主规则经验手册条目，遇到直接套用）

- 【经验·原第7条】**表格四件套**：create_table(headers,rows) 建 xlsx（数字自动转数值；值以 = 开头写成公式如 "=SUM(B2:B10)"；theme 选配色，默认 modern 深蓝表头白字+斑马纹）；read_table 读；append_table_rows 追加行；modify_table 改单元格——单个用 cell="B2"+value，**多个格子一次用 cells:{"B2":5,"C3":"=B2*2"} 批量改**，禁止拆成多次调用。**进阶**：多工作表用 sheets 参数（{表名: markdown 或 {headers,rows}}）；合并单元格（如多级表头、总标题行）用 merges 参数（["A1:C1"] 范围数组）；多表文件 read_table 会列出全部表名，读其他表传 sheet 参数。**多张表格截图整理成一个表**：逐张 view_image 读出内容 → 汇总核对 → create_table 成表，有合并表头就配 merges。
- 【经验·原第9条（节选）】二进制文件必须用专用工具：.xlsx 用 read_table，read_file 会拒绝二进制。

## 本册标准流程（原主规则 SOP 条目）

- **表格整理/美化**：用户要求整理表格格式时 → format_table 一键美化（主题化表头、自动列宽、冻结首行、加边框；可传 theme 选配色）。
- **多张表格/数据截图汇总成表**：逐张 view_image（question 写清"把表格按行列完整转录"）→ 思考里对齐列名、核对数值 → create_table（合并表头配 merges；量大可分多个 sheet；要百分比/货币格式、指定字体颜色底色用 styles: [{range:"B2:B10", numFmt:"0.0%", bold:true, bg:"FFF2CC"}]）→ 汇报整理结果和假设。
- **汇总报表**：从多个来源收集数据 → create_table 用 sheets 建"汇总+明细"多工作表，汇总页的合计单元格写 "=SUM(...)" 公式。

## 册内工作流

- **Excel 建表闭环**：create_table（statusMap 状态列自动上色 + wrap 长文本换行）→ 必要时 modify_table 批量改 → 汇报路径。
- **Word 表格三步**：read_word_tables 定位第几个表 → edit_word_table 改内容 / format_word_table 改格式 → 表格多再跑 fix_paper_paging。
- **截图汇总**：逐张 view_image 转录 → 对齐列名核对数值 → create_table（merges 合并表头）。
- **改内容别绕路**：单个格子 cell+value，多个格子 cells 批量，禁止拆成多次调用。
