# PPT 演示文稿工具手册

> 手册版本随应用发布。经验条目以本册为准，禁止编造"第N条"不存在的规则。

## 何时读我

要创建、读取、修改 PPT（.pptx）时先读本册——含大纲写法、全部配色清单、页型规划和排版铁律。首次用 create_pptx 前必读，否则页型标记写错会生成废页。

## 工具详解

### create_pptx

**params**: path(pptx完整路径), title(演示标题——大纲里没有 #cover 页时用它自动合成封面), subtitle(可选,封面副标题), content(PPT 大纲文本,写法见下), target(可选)

**desc**: 创建 PPT 演示文稿（16:9），自动排版。设计系统内置 18 套配色 × 4 种风格 × 5 种页型，页码徽标、标题防溢出（fit:shrink）、正文左对齐、禁同布局连用全部自动处理。页数上限 30 页，超限报错。改大版式别用 edit_pptx 硬凑，重读大纲重生成更快。

**content 大纲写法**（`---` 独占一行 = 翻页符；页块第一行决定页型）：

```
theme: authority          ← 可选，配色（见清单），默认 authority
style: soft               ← 可选，风格 sharp/soft/rounded/pill，默认 soft
---
```

**排版铁律（每篇必做）**：
1. **每页内容克制**：内容页要点 ≤5 条、每条 ≤2 行；表格 ≤8 行（超出自动截断）——PPT 是讲稿提纲不是文档搬家
2. **页型规划先行**：动笔前先数好几个章节、每章几页内容；连续两页同版式=排版失败（表格页/卡片页/引用页交替着来）
3. **配色按主题选**：科技发布会选 technight/techblue/vivid，政企年报选 authority/platinum，论文答辩选 vintage，母婴快消选 candy/mint——色表见下
4. **风格按场合选**：数据密集报告 sharp，常规商务 soft（默认），产品介绍 rounded，品牌发布 pill
5. **禁止堆大纲**：一页塞 8 个要点会被截断丢内容——宁可多开一页

### read_pptx

**params**: path(pptx完整路径), target(可选)

**desc**: 逐页读取 PPT，按【第X页】分页列出（**页序按真实页序**，调过序的文件也读对），每页标题行带结构计数（如"（2图 3形状）"）——改前先看每页有什么。用户给了一份 PPT 要改/要总结/要提问，先 read_pptx 看内容再动手；改完用 read_pptx 复查。

### edit_pptx

**params**: path(pptx完整路径), replacements([{find:"旧文字", replace:"新文字", all?}]) 改文字, actions([{op:"deleteSlide",page:3},{op:"moveSlide",page:2,to:1},{op:"insertSlide",page:1,title:"新页标题",body:"正文\\n多行"}]) 页级删页/调序/加页, target(可选)

**desc**: 三种操作可并列：**replacements** 精准替换文字（自动备份，跨样式碎 run 的句子也能匹配，只改文字不动版式）；**actions** 页级操作——deleteSlide 删第 N 页、moveSlide 把第 N 页移到第 to 位、insertSlide 加新页（page=插到第 N 页后，标题+正文占位版式，body 支持多行）。适合改数据/删多余页/调页序/补一页。**要改配色/版式**就 read_pptx 拿到内容后用 create_pptx 重做，别用替换硬凑。

## 标准工作流

1. **从零做 PPT**：问清场合/页数/主题 → 选 theme+style → 写大纲（封面+目录+每章过渡页+内容页+总结页）→ create_pptx → open_path 交付
2. **改现有 PPT**：read_pptx 看全文（注意每页结构计数）→ 改文字/删页/调序/加页用 edit_pptx；改版式/配色 → 内容提炼成大纲 create_pptx 重做
3. **PPT 里配图**：generate_image 或找本机图片 → 大纲里 `![说明](图片路径)` → 自动右侧混排

## 踩坑经验

1. `---` 必须**独占一行**（前后可有空行），跟内容挤在一行会被当正文
2. 页型标记 `#cover/#toc/#section/#summary` 只认页块**第一行**，写在中间会被当普通文字
3. 没写 `#cover` 时用 title 参数兜底合成封面；没写 `#summary` 的话最后一页内容页就是收尾，不强求
4. 目录条目会自动补 01/02 编号，大纲里不用手写；章节页同理自动编号
5. 表格列宽按内容自动分配，窄列数据长会挤——表头写短词（"渠道"不是"渠道名称分类"）
6. 图片必须本机真实存在路径，远程图片先 transfer_file/下载到本机再引用；图片加载失败不挡生成但页上无图
