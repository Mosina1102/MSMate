# 格式转换手册（convert_file：一个入口转万物）

> 本册管「**格式转换**」：图片互转、图片合成 PDF、文档转 PDF、md 转 docx、音视频转换。
> 核心认知：**转换是确定性操作**——不需要 AI 逐个"处理"，工具直达；批量任务用 paths 数组一次转换。源文件永远不动。

## 何时读我

用户说"转成 XX 格式"、"把这几张图合成一个 PDF"、"docx 转 pdf"、"提取视频里的音频"、"视频转 gif"时读本册。

## 工具详解

### convert_file

**params**: path(单个源文件完整路径)或paths(数组批量,同目标格式), to(目标格式), out(可选,输出路径;多张图转 pdf 合成一册), extraArgs(可选,音视频附加 ffmpeg 参数数组)

**desc**: 格式转换大全。**源文件永远不动**；输出已存在自动备份再覆盖；批量传 paths 数组（同目标格式）。

## 支持矩阵（对号入座）

| 源格式 | 目标 | 说明 |
|---|---|---|
| png / jpg | pdf | 单图一页；**paths 传多张 = 多页合成一册**（扫描件/截图归档神器） |
| docx / doc | pdf | 需本机装有 Word 或 WPS（COM 导出，三引擎自动降级） |
| html / htm | pdf | 打印渲染，背景色保留，A4 自动分页 |
| md / txt | pdf | 先自动转 docx 再导 pdf（同上依赖 COM） |
| md / txt | docx | markdown 排版引擎直转（标题/列表/表格行/插图） |
| png / jpg / webp / gif / bmp / avif | png / jpg | Chromium 解码器通吃；jpg 输出质量 92 |
| mp4 / mov / avi / mkv / flv / webm | mp4 / webm / mkv / avi / mov / flv | 音视频互转（FFmpeg 首次自动下载约 80MB，终身离线） |
| 视频（mp4/mov/...） | mp3 / m4a / wav / aac / flac | 提取音频 |
| 视频 | gif | 默认取前 10 秒、12 帧（extraArgs 可改） |

**源类型决定路由，改目标前先看源**：`convert_file(path:"报告.docx", to:"pdf")`；`convert_file(paths:["1.png","2.png","3.png"], to:"pdf", out:"归档.pdf")`。

## 本册工作流

- **扫描件归档**：pdf_to_image 转出的整页 PNG 或拍照 jpg → convert_file(paths:[...], to:"pdf", out:"归档.pdf") 一册带走
- **投稿/交材料**：docx → pdf（对方看版式不走样）；md 笔记 → docx 再 → pdf
- **表情包/动图**：视频片段 → gif（默认 10 秒，extraArgs:["-t","5"] 可改时长）
- **提取音频**：演唱会视频 → mp3
- **批量图片转格式**：paths 数组一次转完（50 张 heic/webp → jpg 场景）

## 册内铁律

1. **源文件不动**：转换永远产新文件，绝不原地改写；输出已存在会先备份。
2. **docx→pdf 依赖本机 Office**：没装 Word/WPS 时明确告诉用户"需要装有 Word 或 WPS"，别空转重试。
3. **FFmpeg 首次下载约 80MB**：提前告诉用户"第一次用音视频转换要下载引擎（约 80MB，一次下载终身离线）"，别让用户以为卡死。
4. **gif 默认前 10 秒**：用户要全片/自定义时长用 extraArgs:["-t","秒数"]。
5. 跨域转换按源找分册：pdf 拆合并见 word文档.md，图片处理（缩放/裁剪/抠图）见图片视频.md。

## 常见翻车与自救

| 症状 | 原因 | 自救 |
|---|---|---|
| docx→pdf 报"需要本机装有 Word 或 WPS" | 用户机器没装 Office 套件 | 告知安装任一即可；或改走 html→pdf（无依赖） |
| avif 转 png 报"不可识别的图片" | 极老版本解码器不含 avif | 换 png/jpg 源，或先升级应用 |
| 视频转 gif 文件巨大 | gif 无压缩帧全存 | 降帧 extraArgs:["-r","8"]、限时长、缩尺寸 extraArgs:["-vf","scale=480:-1"] |
| md→pdf 表格错乱 | md 表格经 docx 排版引擎 | 复杂表格先 md→docx 检查效果再转 pdf |
