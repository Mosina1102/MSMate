# 设计手册（海报/封面/卡片：AI 排版渲染工作流）

> 本册管「**视觉设计**」：海报、公众号封面、小红书卡片、简历、邀请函、活动横幅。
> 核心认知 1：**带文字的设计图必须用排版渲染，禁止用生图模型硬画文字**——生图模型的中文文字十次九次乱码。
> 核心认知 2：**素材零准备是本份**——用户没给素材就自己搞，三路供给：实景图 download_file 下载 / 风格化图 generate_image 生成 / 实物主体 remove_bg 抠成透明底。开工前只跟用户对口径（风格/数量），不伸手要素材。
> 核心认知 3：**先立美学方向再动手，禁模板答案**——渲染质量的上限取决于写 HTML 时的设计决策，不是自检修补。写第一行 CSS 前先回答："这张图的美学宣言是什么？第一眼焦点是什么？"（见第四节）
> 正确管线：`定美学方向 → 备素材（三路）→ write_file 写 HTML → render_html 出 PNG → view_image 自检（含审美关）→ 改了重渲`。

## 一、工作流（五步闭环）

```
① 备素材（三路按需混搭，全都不用用户提供）：
   实景照片 → web_fetch(mode:"images") 找图 → download_file 下载
   风格化插画/背景 → generate_image 生成（交付时注明"AI 示意图"）
   产品/人物/宠物主体要叠到别的背景上 → remove_bg 抠成透明底 PNG
② write_file：写单文件 HTML（CSS 全部内嵌 <style>，按画布 CSS 尺寸写死，见第二节）
③ render_html：path=HTML 路径, preset=画布, scale=2（要打印/高清时）
④ view_image：必须自检！看四样——文字溢出没有/对比度够不够/有没有大空洞/对齐齐不齐
⑤ 有问题改 HTML 重渲（一两轮内收敛），交付时报告 PNG 路径
```

示例（用户说"做一张重庆火锅节的海报"）：

```
① 备素材：download_file 下载 2 张火锅实景图；主角"毛肚"要抠出来叠标题旁
   → remove_bg(毛肚.jpg) 得透明底 PNG（生成 -抠图.png 在原图旁）
② write_file: "C:\...\火锅节海报.html"
   <!DOCTYPE html><html><head><meta charset="utf-8"><style>
   body{margin:0;width:1240px;height:1754px;position:relative;
        background:linear-gradient(160deg,#8a1f1f 0%,#c0392b 55%,#f5c451 100%);
        font-family:"Microsoft YaHei","PingFang SC",sans-serif;color:#fff}
   .title{font-size:110px;font-weight:900;letter-spacing:8px;...}
   </style></head><body>...</body></html>
③ render_html(path:同上, preset:"a4", scale:2)     ← 输出 2480×3508 高清
④ view_image(渲染出的 PNG) → 发现"副标题贴到日期了" → 调 margin 重渲
⑤ 交付：PNG 路径 + 一句"文字均为真实排版可后续改 HTML"
```

## 二、画布预设（render_html preset 参数）

| preset | 尺寸（CSS） | 用途 |
|---|---|---|
| `a4`（默认） | 1240×1754 | 竖版海报、简历、邀请函（A4 比例） |
| `xhs` | 1080×1440 | 小红书图文 3:4 |
| `square` | 1080×1080 | 微信/朋友圈分享 1:1、Instagram |
| `wide` | 2100×900 | 微信头条封面 21:9、活动横幅 |
| `wechat-cover` | 900×383 | 公众号次条封面 |
| width/height | 自定义 | 覆盖 preset（如 logo 需要 512×512 就显式传） |

**HTML 必须按 CSS 尺寸写死画布**：`body{width:1240px;height:1754px;overflow:hidden}`——内容超出会被裁掉，所以字号/间距要按尺寸给绝对值（标题 80-120px、正文 24-32px 这个量级），不要用相对单位猜。

## 三、素材用法细节（抠图/实景/生成图各就各位）

- **remove_bg 抠图是合成类设计的主力**：主体抠成透明底后，`<img src="file:///...-抠图.png">` 在 HTML 里自由叠加、任意换背景、配 CSS `filter: drop-shadow(...)` 加投影融合更自然。人像/宠物/产品/物体主体效果好；发丝边缘偶有毛边，给素材加轻微阴影可弱化。
- 实景图要叠字时压深色遮罩（`linear-gradient(rgba(0,0,0,.55),rgba(0,0,0,.2))`）保文字可读。
- 白底素材不抠也可融进浅色背景：CSS `mix-blend-mode:multiply`。
- 批量候选图用 `view_image(paths:[...])` 一次看多张，挑好的上。

## 四、先定美学方向（三种气质配方 + AI 味黑名单）

**写 HTML 前用一句话立美学宣言**（学 canvas-design：先定"美学运动"再表达），并回答两个问题：第一眼焦点是什么？这条宣言适配内容吗？**玩梗/抽象内容禁止走"高端产品海报"路线**——梗的笑点就是设计方向。

### 配方 A：玩梗海报（新丑风/大字报）——梗图、抽象整活、朋友圈疯传款
- **满、大、撞**：大色块铺满或撞色对撞（红配绿、黄配紫，敢用 complementary），元素排到版面 90% 满，**禁止大留白**——留白是给高级感的，梗图要的是信息轰炸的喜感
- 主标题超大：**字高占画布宽度的 18-25%**，可描边、可倾斜、可逐字换色；金句用第二字号铺满中段
- 贴纸感：色块便签、粗黑描边（3-4px）、印章/胶带/便签元素、轻微旋转（-3°~3°）营造手作喜感
- 参考气质：小红书热梗图、B 站封面、"暴走漫画"排版密度

### 配方 B：Editorial 编辑风（叙事型）——活动邀请、品牌故事、图文卡片
- 大标题 + 分层小字，杂志排版感；衬线中文用宋体系（"SimSun"/"Noto Serif SC"）提升气质
- 留白大方：内容占版面 60-70%；图片作背景压深色遮罩保文字可读
- 配色：底色+文字+**一个**强调色，全场不超过三个色系

### 配方 C：Swiss 网格风（数据型）——KPI 卡片、对比图、教程步骤
- 网格优先：`display:grid;grid-template-columns:repeat(2,1fr)`，块间 24-32px
- 数字大、标签小：数据点字号是标签的 3 倍起；细线分隔代替色块
- 强调色只给最重要那一个数字/结论

### AI 味黑名单（自检时命中即重做，学官方 frontend-design"拒绝通用 AI 美学"）
1. **圆形头像框 + 右侧编号小框列表**（01/02/03 竖排小框）——模板答案头号特征
2. **底部四个等宽小卡片一排**堆数据（蛋白质/钙/零添加/海拔式）——数据要融进版式，不要格子化
3. 居中对称 + 上下等分 + 米白底 + 细描边圆角按钮——"Word 思维"排版，海报禁用
4. 全图无一个"大"元素：最大字号与正文差不到 3 倍 = 没有视觉层级 = 重做

**尺度硬标准**：主标题字高 ≥ 画布宽的 12%（梗图 18-25%）；主体视觉（图/大字块）占版面 ≥ 40%；任何连续空白区 ≤ 版面 15%。

## 五、版式骨架速查（挑一个再填内容）

| 内容类型 | 骨架 |
|---|---|
| 活动海报 | 顶部主标题（40%高度）→ 中部时间地点三行大字 → 底部主办方小字条 |
| 数据卡片 | 顶部结论一句 → 中部 2×2 KPI 网格 → 底部来源注释 |
| 图文封面（xhs） | 上 1/2 配图（generate_image 素材）→ 下 1/2 大标题+三个要点图标行 |
| 简历 | 左 1/3 深色侧栏（姓名/联系方式/技能条）+ 右 2/3 正文时间线 |
| 对比图 | 左右两栏卡片 + 中间 VS 徽章，差异行用对勾/叉图标 |

## 七、自检清单（view_image 时逐项过，功能关 + 审美关）

**功能关**：
1. 文字有没有溢出画布/被裁切（尤其长标题）
2. 文字与背景对比度够不够（浅底浅字=失败）
3. 有没有大片空洞（连续空白 > 版面 15% = 失败）
4. 对齐：左对齐就全线左对齐，别忽左忽中
5. 字号层级：一眼能分出"标题/副标/正文"三级
6. 引用的本地图片真的加载出来了（没加载=灰框，换 generate_image 重出或改用纯排版）

**审美关**（不过关就改 HTML 重渲，别交付）：
7. 命中 AI 味黑名单没有（圆头像+小框列表/四卡片堆数据/Word 思维居中对称）
8. 第一眼有没有焦点——眯眼看缩略图还能不能认出"这张图想让我看什么"
9. 风格配对内容没有（玩梗却做成高端海报 / 正式邀请却做成大字报 = 方向性返工）
10. 敢不敢发朋友圈——自己都不想转的图，别交给用户。

## 八、与其它工具的组合

- 素材供给三路见第三节（实景 download_file / 生成 generate_image / 抠图 remove_bg），嵌 HTML 用 `<img src="file:///完整路径">`（注意三斜杠）
- 抠图配 render_html 合成、配 create_word 插图都干净（透明底不压底色）
- 配色没头绪：`web_fetch` 抓参考站取色值，别凭空猜品牌色
- 产出进 PPT/Word：PNG 交给 `create_pptx`/`modify_word` 插图
- 批量尺寸：同一 HTML 复用，`render_html` 换 preset 多跑几轮（square + xhs 一稿两用改少量 CSS 即可）

## 九、边界

- 渲染离屏窗口在应用内可用；AI 写的 HTML 若引用网络资源（字体/CDN），网络不通时按已有系统字体渲染，不影响出图
- 不做交互式设计稿（只出静态 PNG/PNG 多尺寸），要改稿改 HTML 重渲
- 印刷场景建议 scale≥2 出图（300dpi 级）
