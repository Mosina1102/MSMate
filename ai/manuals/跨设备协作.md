# 跨设备协作工具手册

> 手册版本随应用发布。经验条目以本册为准，禁止编造"第N条"不存在的规则。

## 何时读我

任务涉及两台及以上设备（复制/传输/在远程设备上创建文件）时先读本册——三步套路和路径规则都在这里。单设备操作不需要本册。

## 工具详解

### transfer_file

**params**: src_path(源文件完整路径), src_target(源设备,可选默认local), dest_target(目标设备,可选默认local), dest_dir(目标文件夹的完整磁盘路径,如 C:\Users\<用户名>\Desktop——禁止传"桌面"这类列表显示名)

**desc**: 跨设备复制文件（从一台电脑复制到另一台）。"把对方/远程电脑的文件复制过来/传过去"就用这个；同设备复制请用 copy_path。dest_dir 必须完整路径，不确定对方用户名就先 list_dir(path:"C:\\Users", target:设备) 探查

## 本册经验（原主规则经验手册条目，遇到直接套用）

- 【经验·原第15条】**任务涉及多台设备**：每一步在思考里标注 target，逐台设备分别完成并分别汇报（本机完成了什么、远程完成了什么）。
- 【经验·原第16条】**远程设备操作失败提示"设备未连接/不存在"**：说明 target 填错或设备掉线了。先对照"当前可用设备"清单检查 deviceId，设备确实掉线就告诉用户重新连接，**禁止偷偷改用本机执行**。

## 本册标准流程（原主规则 SOP 条目）

- **跨设备复制/传输**："把对方(远程)的 xx 复制过来" → transfer_file(src_path=远程完整路径, src_target=远程deviceId, dest_dir=本机接收文件夹)；"把本机的 xx 传给他" → transfer_file(src_path=本机路径, dest_target=远程deviceId, dest_dir=远程文件夹)。不要用 copy_path/move_path（它们不能跨设备）。
- **跨设备创建文件（如"在 xxx 桌面上建一个 xx"）——固定三步套路，禁止直接往远程瞎写**：
  ① **本机先做出来**：write_file/create_word/create_table 在本机工作目录（或临时目录）把文件做好，target 不传（就是本机）；
  ② **探明远程路径**：list_dir(target=对方设备, path="root") 找"桌面"条目 → 拿到对方桌面的真实完整路径。**每台电脑用户名不同，远程路径必须探出来，禁止拿本机路径换台机器拼**；
  ③ **transfer_file 传过去**：transfer_file(src_path=本地文件路径, src_target=local, dest_target=对方设备, dest_dir=对方桌面路径) → list_dir 对方桌面确认文件已到 → 汇报"本机临时文件 + 远程落点"两个路径。
  要"建过去且本机不留"= 跨设备移动：③ 确认成功后再 delete_path 删本地原件，顺序不能反。
  远程建文件夹：路径确认后直接 create_folder(target=对方设备, path=完整路径)。远程路径已经 list_dir 确认过存在时，纯文本小文件也可以 write_file 直接带 target 写；**没探过路径就拿不准的，一律回到三步套路**。
- **跨设备任务**：确认目标设备的 deviceId → 在目标设备 list_dir 确认目录存在 → 执行操作 → 分别汇报两台设备的结果。
- **跨设备移动**（复制过去并删掉原件）：先 transfer_file 确认复制成功，再 delete_path 删除源文件，分两步做，禁止一步到位。

## 册内工作流

- **三步套路速记**：本机做 → list_dir 探远程真实路径 → transfer_file 传过去 → list_dir 确认到达。禁止猜远程路径直接写。
- **target 判定**：用户说"我电脑/这边/本机"→ local；"远程/那台电脑/设备名"→ deviceId（支持用户备注的模糊匹配，多台命中就用完整 deviceId）。
- **传输失败排查**："设备未连接/不存在" = target 填错或掉线，对照设备清单检查，掉线就请用户重连，禁止改用本机顶替。
- **汇报格式**：跨设备任务分别汇报两台设备各自完成了什么。
