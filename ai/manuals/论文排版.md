# 论文排版工具手册

> 手册版本随应用发布。经验条目以本册为准，禁止编造"第N条"不存在的规则。

## 何时读我

涉及"论文格式/学校模板/套格式/格式体检/参考某文档改格式"时先读本册。普通 Word 创建/修改（不涉及格式规范）用 word文档.md。

## 工具详解

### read_word_format

**params**: path(docx完整路径), mode(可选,默认fingerprint格式指纹;full=逐段全量格式清单)

**desc**: 解析 Word 文档(.docx)的完整格式（本机文件）：字体/字号/颜色/加粗/行距/对齐/缩进/段前后距/页边距/页眉页脚。fingerprint 模式返回格式指纹（各级标题+正文的格式方案+页面设置，AI 直接可读）；full 模式逐段列出文字与生效格式（长文档截断 200 段）。**格式级联已算好**：样式表/继承链/文档默认值全部折算成每段的"实际生效格式"。参考 A 的格式改 B 的工作流：①read_word_format(A) ②read_word(B) ③apply_word_format

### read_paper_spec

**params**: path(格式模板docx完整路径), target(可选)

**desc**: **把论文格式模板蒸馏成"格式规范书"（几百字）**——学校模板本质是写给学生的格式说明书：批注里是权威规则（如"三号，黑体，1.5倍行距"，自动解析成结构化格式并按锚定位置归属角色）、红字是说明书正文（原文收录）、示范文字只是格式载体。返回：页面设置/分节页码（罗马·阿拉伯）/各角色格式（封面·摘要排头·关键词·各级标题·正文·页眉页脚）/批注规则清单/红字说明书原文/校徽等图片资产路径。**规范书就是"逐段提取模板格式"的依据**——封面格式、摘要格式、正文格式、参考文献格式都在里面，按板块逐段对照修改时每段先回来看对应角色的要求。**分段循环工作流（正确 > 速度）**：read_paper_spec(模板) 拿规范书 → 按板块逐段做（封面→摘要→关键词→目录→正文→参考文献）：每段"看规范书要求→改产出→check_paper_format 验证该节→✓ 才进下一段"；不要 read_word 模板全文（撑爆上下文）；规范书不够明确时（版面布局/下划线位置等）把模板拖进工作台 screenshot + view_image 识图补齐。模板的红字/批注/说明书内容一个都不要带进产出

### check_paper_format

**params**: path(套模板后的产出docx完整路径), templatePath(格式模板docx完整路径), target(可选)

**desc**: **产出论文体检（自我检查闭环）**：对照模板规范书逐项检查产出文档——红字/批注/示范占位符残留、各级标题与正文的字体字号行距缩进是否符合批注规则、正文 [数字] 引用是否上标、手动序号是否连续跳号、参考文献条目格式。返回**逐节对照进度表**（封面/摘要/关键词/目录/正文/参考文献每节显式 ✓/✗——✓ 的节才算过，✗ 列待修项）+ 按严重度排序的 issue 清单（每条带位置+期望+实际+修法）。**分段循环工作流（老大定规：正确 > 速度，宁可多步不可做错）：一次只做一个板块 → 改完立刻跑本工具 → 该节 ✓ 才进下一板块 → ✗ 就修再复查该节 → 六节全 ✓ 才算完成。禁止一次全改完不验证就交差**。程序检查不漏项，AI 修正管语义（引用上标/序号措辞）

### apply_word_format

**params**: path(要改的docx完整路径), formatPath(格式参考A的docx路径,rules用"source"时必传), rules(套用规则), target(不支持远程)

**desc**: 把格式套用到 Word 文档（本机文件），**内容一字不动只改格式**。rules 两种形态可混用：①角色映射 map:{title/h1/h2/h3/quote/list/body:"source"或格式对象}——按文档结构批量套（"source"=用 formatPath 文档对应角色的格式，A 缺该角色降级用 A 的正文格式）；②精准挑选 picks:[{match:"B段落开头连续文字", format:{font,eastAsiaFont,sizePt,bold,italic,color,shade,lineRatio,linePt,beforePt,afterPt,indentFirstLine,align,underline}}]。示例：{map:{h1:"source",h2:"source",body:"source"}} 整体参考 A；{picks:[{match:"第三章",format:{sizePt:16,bold:true,color:"FF0000"}}]} 单段精准改。⚠ **改论文格式禁用本工具**——论文要按学校模板改：走 read_paper_spec(模板) → apply_word_template(论文,模板,cover) → check_paper_format 闭环（模板的封面校徽图片/页眉/分节页码/目录域只有 apply_word_template 会迁，拿另一篇论文当 formatPath 套出来的格式本身就是错的）。本工具适合：普通文档参考 A 改 B、体检后按 issue 逐段 picks 精修。修改前自动快照备份可还原

### apply_word_template

**params**: path(论文docx完整路径), templatePath(学校格式模板docx完整路径), cover(可选封面字段对象:title题目/college学院/major专业/grade年级/studentId学号/name姓名/advisor指导教师/date日期), outputPath(可选输出路径,默认"论文名-套模板格式.docx"), target(不支持远程)

**desc**: 论文套学校格式模板（本机文件）：**模板当骨架、论文当血肉**——保留模板的封面（**校徽等封面图片、原创性声明/授权页自动迁入**）/页眉页脚/分节页码（前置罗马数字、正文阿拉伯数字从1起）和纸张设置，把论文的题目/摘要/关键词/正文（含图片、列表）按模板标题与正文字体重排迁入，表格自动转三线表、网页残留格式（黑底/彩字/网页字体）全清，目录替换为可更新的目录域。**产出零批注零红字零格式说明书**（模板批注/红字/"三号黑体，居中"式示范说明段/注意事项页自动剔除不迁入）。**cover 建议必传**：先问用户或从论文提取（学院/专业/年级/学号/姓名/指导教师/日期），不传则封面保留模板示范值（XXX/占位日期会原样留在封面上）。**分段循环工作流（正确 > 速度，宁可多步不可做错）**：①read_paper_spec(模板) 领会规范书（.doc 自动转换） ②本工具整套套用（骨架/图片/页眉/分节/目录域一步到位） ③check_paper_format 看逐节对照进度表——✗ 的板块用 apply_word_format picks 精修/modify_word 补内容，修一个板块复查一次，**六节全 ✓ 才算完成，禁止套完不验就交差**。改论文格式必须走本工具（apply_word_format 只改 run 格式，封面图片/页眉/分节/目录域全带不过去）

## 册内工作流

- **论文套模板闭环（主线，正确 > 速度，宁可多步不可做错）**：
  ① read_paper_spec(模板) 领会规范书（.doc 自动转换）
  ② apply_word_template(论文, 模板, cover) 整套套用——骨架/封面图片/页眉/分节页码/目录域一步到位
  ③ check_paper_format 看逐节对照进度表 → ✗ 的板块用 apply_word_format(picks) 精修或 modify_word 补内容
  ④ 修一个板块复查一次，六节全 ✓ 才算完成，禁止套完不验就交差
- **普通文档参考 A 改 B**（非论文）：read_word_format(A) → read_word(B) → apply_word_format(map 或 picks)。
- **体检后精修**：按 check_paper_format 的 issue 清单逐条 apply_word_format(picks) 定点改，改完复查。
- **cover 字段**：学院/专业/年级/学号/姓名/指导教师/日期不齐时先问用户或从论文提取，别让封面留 XXX/占位日期。
