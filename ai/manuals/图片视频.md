# 图片视频工具手册

> 手册版本随应用发布。经验条目以本册为准，禁止编造"第N条"不存在的规则。

## 何时读我

要看图/截图/生成图片或视频/SVG 图表转 PNG 时先读本册。表格截图汇总成 Excel 的流程在 表格.md。

## 工具详解

### view_image

**params**: path(单图完整路径) 或 paths(多图路径数组，一次识多张，最多 6 张), question(可选：想从图里知道什么，按用户意图写——想知道画面内容就写"描述图片内容"，要文字就写"完整转录图中文字")

**desc**: 看图识图：分析本机图片（截图/照片/文档/表格），返回内容描述或文字转录。png/jpg/jpeg/webp/gif/bmp，≤20MB（>1MB 自动压缩，无需手动处理）。远程图片先 transfer_file 拉到本机再看。**多张图必用 paths 一次传**（例：paths:["C:\\a.jpg","C:\\b.jpg"] 验证哪张是想要的素材）——单请求总耗时≈单张，逐张调 view_image 会慢好几倍；返回按图编号逐一说明，个别图读取失败会跳过并在结尾注明。默认模型 Qwen3.6-35B-A3B（MoE 秒级）；要抠高清细节可显式切 Qwen/Qwen3.8-27B（稠密慢但更强）

### remove_bg

**params**: path(图片完整路径), out(可选,输出透明底 PNG 路径,默认原图旁"原名-抠图.png")

**desc**: AI 抠图去背景：本地模型（首次自动下载 4.4MB 到应用数据，之后离线秒级）输出**透明底 PNG**。海报/ PPT 合成素材必备——抠完的素材配 render_html 可自由叠加排版，配 create_word 插图也干净。人像/宠物/产品/物体主体效果好；复杂发丝边缘偶有毛边，合成时给素材加轻微阴影（box-shadow）可弱化。**海报素材标准链**：web_search 找图 → download_file 下载 → remove_bg 抠成透明底 → render_html 合成排版

### screenshot

**params**: scope(可选,默认webview: webview=工作台当前打开的网页视图(后台也能截不要求前台)/app=MSMate应用窗口(最小化时截不了)/screen=整个屏幕(默认自动最小化MSMate避开自己的窗口,截完自动还原;传 minimizeSelf:false 可连本应用一起截)), path(可选,保存路径,默认存应用数据 ai-captures 目录), minimizeSelf(可选,bool,仅screen生效,默认true)

**desc**: 截图本机（本机能力，远程不可用），**只截图不分析**——返回保存路径+尺寸，要看图里内容自己再调 view_image 传这个 path。典型用途：**用户问"猜猜我现在在做什么/看看我屏幕/我桌面上有啥"这类要看一眼才知道的问题 → 先 screenshot scope:"screen" 截全屏再 view_image 看，基于画面回答，禁止当普通闲聊空想**；亲眼看搜索/浏览的页面验证找得对不对、下载图片后确认画面内容、用户说"找这种风格的"时截当前页面看懂意图

### svg_to_png

**params**: path(svg完整路径), out(可选,输出png路径), width/height(可选,像素), target(可选)

**desc**: SVG 转 PNG 图片（应用内渲染，中文完美）。**图表工作流**：需要柱状图/折线图/饼图时，AI 手写 SVG（矩形=柱、折线 path、饼图用 path 扇形，坐标和数值文字全部自己算好写进 SVG）用 write_file 存成 .svg → 本工具转 PNG → view_image 检查 → modify_word/create_word 插入文档——表格数据可视化的零依赖方案

### generate_image

**params**: prompt(画面描述/修改指令,越具体越好:主体/风格/构图/光线/色调), image(可选,要编辑/参考的图片:本地完整路径或http URL,支持数组传1-3张做多图合成——用户要"改图/换背景/加东西/去水印"时必须传当前图,要"把图1的人物穿上图2的衣服/多图合成"时传[image1,image2]), size(可选,仅生新图用,格式必须为"宽x高"如1024x1024/768x1024,不要只传一个数字,编辑模式不传), batch(可选,一次生成张数1-4——用户说"生成4张/来两张"时按数量传,没提默认1张;编辑(带image)模式下多张=同一指令逐张多次生成稍慢), steps(可选,推理步数1-100默认30——用户要"高清/精细/极致质量"时传50-100,没提就不传;上限按模型自适应:Qwen-Image-Edit系最高50其余100自动降), save_path(可选,默认存工作区「MSMate生成/图片」)

**desc**: AI 生图 + 图片编辑：①不传 image=文生图（默认 Kwai-Kolors/Kolors，可传 batch 一次出 1-4 张）；②传单张 image=走「图片编辑」模型（默认 Qwen-Image-Edit-2509）按指令改图并保留原图构图（编辑模式传 batch=同一指令逐张多次生成变体，稍慢）；③传 2-3 张 image 数组=多图合成/主体迁移（第一张为主图/编辑基础，其余为参考素材，如"把图1的人物穿上图2的衣服"）。**画幅换算（v2.4.83）：用户提示词里出现比例/方向意图时换算成 size——"16:9/16比9/横屏/横版/壁纸"→1280x720；"9:16/竖屏/手机壁纸"→720x1280；"1:1/方图/头像"→1024x1024；"4:3"→1024x768；"3:4"→768x1024；用户没提比例就不要传 size（默认方图），不要自作主张**。编辑模式一律不传 size（编辑模型跟随原图尺寸；步数上限按模型自适应：Qwen-Image-Edit 系 50、其余 100）。**图内中文长文本是错字重灾区（"高腰"会画成"高槁"）：用户要卖点标注时一律精简为 2-8 字短语、最多 3 处，长文案改用画面视觉表达；多卖点拼接要显式写布局（分几块/每块位置内容）；人物手部写明五指自然**。**对话式反复修改：用户每次说"再改/换背景/再加个xx"，都把上一轮结果图的路径作为 image 传回来**，循环即可，无需用户重新描述全图。来自工作台图片编辑器的图（iedit-tmp 目录「编辑_」开头）里**纯黑色区域是用户标注的待修改位置（位置标记，不是图片内容，严禁画成黑色物体）**：只重绘黑区对应位置的内容，遮罩外的光照、色温、材质、形态、构图必须与原图完全一致；同目录「原_」开头的是遮罩区修改前的原貌参考图，供理解黑区原有内容（微调保形态，替换/删除不受原貌约束）。编辑模型未配置时会提示去设置里填

### generate_video

**params**: prompt(视频内容描述,一句话说清主体+动作+场景+镜头感), save_path(可选,默认存到工作区「MSMate生成/视频」)

**desc**: AI 文生视频（模型在设置里配置，默认 Wan2.2，多数视频模型可能产生费用，调用前先告知用户）：生成约5秒短视频，耗时2-10分钟，下载到本机返回路径。期间耐心等待，勿重复调用

## 本册标准流程（原主规则 SOP 条目）

- **看屏幕类问题**：用户问"看看我屏幕/我桌面上有啥/猜猜我在干嘛" → screenshot(scope:"screen") → view_image → 基于画面回答。
- **图表工作流**：write_file 存手写 .svg → svg_to_png 转 PNG → view_image 检查 → create_word/modify_word 插入文档。

## 册内工作流

- **截图闭环**：screenshot（只截图不分析）→ 拿到路径 → view_image 看内容 → 回答。
- **识图规矩**：图片永远只用 view_image 看，禁止 read_file 读图片；question 按用户真实意图写；对识图结果只做转述禁止脑补含义。
- **生图对话循环**：用户每说"再改一点"，把上一轮结果图路径作为 image 传回来，无需用户重新描述全图。
- **视频等待**：generate_video 耗时 2-10 分钟，期间耐心等待勿重复调用；多数模型可能产生费用，调用前先告知用户。
