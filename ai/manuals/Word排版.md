# Word 排版工具手册（论文为主，普通 Word 格式任务通用）

> 手册版本随应用发布。经验条目以本册为准，禁止编造"第N条"不存在的规则。

## 何时读我

涉及"改文字/改格式/套格式/排版/学校模板/论文格式/格式体检/参考某文档改格式"时先读本册。纯新建文档（不涉及既有内容与格式规范）直接用 word文档.md 的 create_word。

本册的核心不是工具清单，是**先分清用户要干哪种事**——动文字？动格式？有没有参照物？选错链=返工。

## 一、先选路：任务路由表（全手册核心）

用户一句话里往往混着多件事，先按下面表对号入座，拆成对应的标准链：

| 用户要干的 | 动文字? | 动格式? | 标准链 | 详见 |
|---|---|---|---|---|
| 纯改文字（润色/改错/补内容） | ✓ | ✗ | read_word → modify_word → 复查 | §3.1 |
| 纯改格式（普通文档，参考 A 或口述要求） | ✗ | ✓ | read_word_format(A) → apply_word_format → 指纹复查 | §3.2 |
| 纯改格式（论文套学校模板） | ✗ | ✓ | read_paper_spec → apply_word_template → check_paper_format 循环 | §3.3 |
| 又改文字又改格式 | ✓ | ✓ | **先走文字链定稿 → 再走格式链**，两步分开 | §3.4 |
| 半成品格式已乱（只修不重建） | ✗ | ✓ | 摸底 → 局部 picks 修 或 重套模板 | §3.5 |
| 格式要求是 PDF/网页/截图（无模板 docx） | ✗ | ✓ | 提炼规范书 → apply_word_format 逐角色套 → 逐条核对 | §3.6 |
| 新建文档/论文 | ✓ | ✓ | create_word 先定内容 → 再进格式链 | → word文档.md |

### 三条铁律（违反=返工）

1. **文字与格式分离**：工具天生分工——modify_word 只动字，apply_word_format/apply_word_template 只动格式。用户一句话要两样时**拆成两步分别交付**（"先按您说的改完文字，格式我第二步套"）。混着做=两头不讨好，出了问题都说不清哪步引入的。
2. **每步验产物**：改完 read 一眼确认内容完整；套完必须 check；格式动了必须指纹复查。上一步没验证过，下一步不动手。
3. **分段循环（正确 > 速度，宁可多步不可做错）**：格式类任务一次只做一个板块，改完立刻复查，该节 ✓ 才进下一段，禁止一次全改完不验证就交差。

## 二、工具分工表（谁管文字、谁管格式、禁区）

| 工具 | 管文字 | 管格式 | 一句话定位 | 禁区 |
|---|---|---|---|---|
| read_word | 读 | — | 读文本结构与内容 | 别拿去读模板全文（撑爆上下文，用 read_paper_spec） |
| modify_word | 写 | ✗ | 精准改文字（自动转工作台改稿副本） | 别拿来改格式 |
| create_word | 造 | 部分 | 新建文档 | 既有文档禁止重造（丢内容风险） |
| read_word_format | — | 读 | 格式指纹/逐段全量清单 | — |
| read_paper_spec | — | 蒸馏 | 模板 docx → 格式规范书 | 只吃模板，别喂论文 |
| apply_word_format | ✗保证 | 改 | 内容一字不动改格式（map 角色批量 / picks 单段精修） | **改论文格式禁用**——封面图片/页眉/分节页码/目录域全带不过去 |
| apply_word_template | 迁移 | 整套 | 论文套学校模板（模板当骨架、论文当血肉） | cover 不传=封面留模板占位 XXX |
| check_paper_format | — | 验 | 逐节体检（✓/✗ 进度表 + issue 清单） | 必须 templatePath，无模板场景用不了（§3.6） |
| fix_paper_paging | ✗ | 修 | 表标题不与表格拆页、跨页重复表头 | 归册表格.md，表格多/长时最后跑一次 |

**为什么改论文必须走 apply_word_template（而不是 apply_word_format）**：论文模板的校徽等封面图片、原创性声明/授权页自动迁入、页眉页脚、前置罗马/正文阿拉伯分节页码、可更新目录域，只有 apply_word_template 会迁——apply_word_format 只改字面格式，拿另一篇论文当格式参考套出来的本身就是错的。**改论文格式必须走本工具**。

## 三、六条标准链

### 3.1 纯改文字（论文/普通 Word 通用）

```
① read_word 摸底（同时留存原文——改稿副本机制已自动备份，可还原）
② modify_word 精准修改（定位串唯一；多处同类修改用数组批量）
③ read_word 复查：改动处上下文各读一段，确认改对且没误伤
```
- 禁区：不要为了"改几个字" create_word 重造全文；不要顺手"帮忙"调整格式（用户没要求）。
- C 盘保护区文件：modify_word 自动转工作台「改稿」副本，原文件不动留作对比，多轮修改智能沿用副本。

### 3.2 纯改格式·普通文档（参考 A 改 B 或口述要求）

```
① 参照物是文档：read_word_format(A) 拿格式指纹（角色级格式方案已折算好）
   参照物是口述："标题小三黑体加粗、正文小四宋体1.5倍"→ 直接写进 map/picks
② apply_word_format：整体参考用 map:{h1:"source",h2:"source",body:"source"}；
   个别段特殊用 picks:[{match:"段落开头文字", format:{...}}]
③ 复查：read_word_format(B) 再取指纹，与 A（或要求）逐角色 diff，✓ 才交付
```

### 3.3 论文套学校模板（主线闭环）

```
① read_paper_spec(模板) 蒸馏规范书（.doc 自动转换）——规范书就是逐段提取模板格式的
   依据，按板块对照时每段先回来看对应角色的要求。规范规则分两级：
   · required＝批注/红字里学校明文写的规则（"三号，黑体，1.5倍行距"）→ 硬性，必须达标
   · inferred＝示范文字推断出的格式（示范段本身）→ 参考级，与规范书冲突时以 required 为准
   规范书不够明确时（版面布局/下划线位置）把模板拖进工作台 screenshot + view_image 识图补齐
② apply_word_template(论文, 模板, cover) 整套套用：封面（校徽等封面图片、原创性声明/
   授权页自动迁入）/页眉页脚/分节页码/目录域一步到位，模板的红字/批注/示范说明段全剔除
   cover 必传建议：学院/专业/年级/学号/姓名/指导教师/日期，不齐先问用户或从论文提取，
   不传则封面保留模板示范值（XXX/占位日期原样留在封面上=事故）
③ check_paper_format 看逐节对照进度表（封面/摘要/关键词/目录/正文/参考文献）：
   ✗ 的板块用 apply_word_format(picks) 精修或 modify_word 补内容 → 复查该节
④ 修一个板块复查一次，✓ 才进下一段；六节全 ✓ 才算完成，禁止套完不验就交差
⑤ 收尾：表格多/长跑 fix_paper_paging（归册表格.md）→ 三级自检（§四）→ 交付
```

### 3.4 文字+格式双改（两步走）

```
① 先按 §3.1 把文字全部改完、复查、向用户报"文字已定稿"
② 再按 §3.2（普通文档）或 §3.3（论文）处理格式
```
- 为什么不混做：modify_word 的改稿副本机制与 apply_* 的快照是两套保护，混做时一步出错无法定位是谁引入的；分开则每步独立可还原。
- 交付话术明确分两步："文字改动如下……确认后我接着套格式"。

### 3.5 半成品修复（格式已乱，只修不重建）

判断标准——**重建还是局部修**：

| 情形 | 走法 |
|---|---|
| 有学校模板 + 全文格式乱/用了错的格式来源 | 别修了，直接走 §3.3 重套一遍（大改直接重建，重套比逐段修快且干净） |
| 有模板 + 只个别节不达标 | §3.3 主线，check 定位 ✗ 节，picks 精修那几节 |
| 无模板 + 个别格式问题（标题不统一/缩进乱/行距花） | read_word_format(full) 摸底 → 归类问题清单 → apply_word_format(picks) 逐类修 → 指纹复查 |

- 半成品摸底必做：read_word_format(mode:"full") 逐段清单里同名角色格式不一致的，就是"乱"的范围，先报给用户再动手。
- 快照可还原：动手前声明，改崩了能回。

### 3.6 无模板场景（格式要求是 PDF/网页文字/截图）

```
① 拿到格式要求：read_pdf / web_fetch / screenshot+view_image 读全要求
② 自己蒸馏规范书：按角色整理成结构化清单（页面设置/封面/摘要/各级标题/正文/
   图表/参考文献——写法对齐 read_paper_spec 的输出），标注每条是明文还是推断
③ apply_word_format 逐角色套（map 用格式对象形态：{h1:{sizePt:16,...},body:{...}}）
④ 自检：无模板时 check_paper_format 用不了（需要 templatePath）——改用三级自检：
   指纹对比 + 规范书逐条核对（每条标 ✓/✗）+ 视觉抽样（§四.③）
```
- 期刊/会议模板若拿到的是 docx 模板 → 照走 §3.3，英文论文同理（字体换成 Times New Roman 等西文字体，规范书照蒸馏）。

## 四、三级自检（每轮格式任务的收尾关卡）

### ① 内容零改动对比（格式任务的信任凭证）

```
动手前：read_word 留存正文（重点记总字数、各章首句、末段）
完成后：read_word 再取 → 比对总字数一致 + 各章首句一致 + 随机抽 3 段逐字核对
交付声明："正文文字零改动，只动了格式"（有快照，不满意可整体还原）
```

### ② 格式指纹对比（改了什么一目了然）

```
动手前 read_word_format(fingerprint) → 完成后再取 → 逐角色 diff
交付时列"动了哪些角色：标题一级 X→Y、正文 A→B…"，没打算动的角色指纹变了=误伤，立即修
```

### ③ 视觉抽样自检（抓程序测不出的版式问题）

程序读 XML 管精确值（字号磅值/行距倍率/缩进），**但页眉横线在不在、目录点线乱不乱、封面校徽位置、下划线对没对齐，程序难测、图一眼看出**——所以关键页要看图：

```
① 产出 docx → PDF（当前过渡路径：请用户在 Word/WPS 里"另存为 PDF"；
   应用内置一键转换工具在后续版本提供）
② pdf_to_image(该PDF, pages:"1-6") 转关键页
③ view_image(paths:[模板对应页, 产出对应页], question:"对比版式：标题层级/居中/页眉页码/
   目录点线/封面布局是否一致") —— 多图并排对比，一次最多 6 张，抽封面/目录/正文首页/
   图表页/参考文献页即可，禁止全文逐页扫（上下文和积分都爆）
```

**识图能力边界（诚实用）**：能看——布局、对齐、页眉页码有无、目录形态、封面结构、字体大类观感（黑体/宋体）、行距疏密；**看不准**——精确字号（小四 vs 五号差 0.5pt）、行距精确倍率、字体全名（仿宋_GB2312 vs 仿宋）、页边距数值。所以视觉自检是兜底网不是主关卡，主关卡永远是 check_paper_format / 规范书逐条核对。

## 五、专项细则

### 封面与 cover 字段
- cover 字段（title 题目/college 学院/major 专业/grade 年级/studentId 学号/name 姓名/advisor 指导教师/date 日期）不齐时**先问用户或从论文提取**，别让封面留 XXX/占位日期。
- 封面下划线对齐靠模板原有结构（表格/制表位），只换文字别动结构；自己用空格凑下划线长度=翻车。

### 图表：题注与三线表
- 题注位置：**图题在图下方、表题在表上方**（国标习惯）；编号全文连续（图1/图2…）或按章（图1-1/表2-3），以学校规范书为准，全文必须统一一种。
- 题注格式：通常五号宋体/黑体不加粗居中——按规范书，别自作主张加粗。
- 三线表：顶线/栏目线/底线三条横线，**无竖线**；粗细常规顶底线 1.5 磅栏目线 0.75 磅（以规范书为准）。工具见表格.md（format_word_table）。
- 表标题不与表格拆页、跨页重复表头：fix_paper_paging 一键修（归册表格.md）。

### 参考文献（GB/T 7714 常见细则）
- 著录格式：`[序号] 作者. 题名[文献类型]. 刊名/出版社, 年, 卷(期): 页码.`；文献类型标识：期刊 [J]、专著 [M]、学位论文 [D]、会议录 [C]、标准 [S]、报纸 [N]、电子资源 [EB/OL]。
- 作者 3 人以内全列，超过 3 人列前 3 位加"，等"（英文 et al）。
- 序号按正文**首次引用顺序**编号；正文引用 `[1]` 上标；引用序号与文末列表**一一对应**（check_paper_format 会查：多引/漏引/跳号都算 ✗）。

### 目录域 / 页眉页脚 / 分节页码
- 目录是**域**不是文字：交付时必提醒用户"右键目录 → 更新域 → 更新整个目录"才显示/刷新页码。AI 在文档里写死目录文字=翻车（页码全错）。
- 前置部分（封面/摘要/目录）罗马页码、正文从 1 起阿拉伯页码——靠**分节符**实现，apply_word_template 自动迁；后续 modify/apply 操作别删分节符。
- 页眉奇偶不同/首页不同的文档，改页眉要分奇偶两套检查。

## 六、常见翻车与自救

| 症状 | 根因 | 自救 |
|---|---|---|
| 目录页空白或页码全错 | 目录是域，没更新 | 提醒用户"更新整个目录"；AI 侧确认 apply_word_template 已换目录域 |
| 前置罗马页码/正文页码混乱 | 分节符被误删 | 重新走 apply_word_template（分节自动重建）；平时 modify/apply 绕开分节符 |
| 改格式"改不动"/改完又弹回 | 样式层与直接格式层冲突，直接格式被样式覆盖 | 用 picks 在段落/run 直接格式层强改；仍不动说明改错对象（改到样式定义去了） |
| 黑底/彩字/网页字体残留 | 从网页粘贴带来 HTML 格式 | apply_word_template 自动清；手动路径 picks 逐段清色+统一字体 |
| 字体看起来不对但 read_word_format 读出的字体名是对的 | 本机没装学校特有字体（方正小标宋等），Word 用替代字体渲染 | 字体名对就不用改，提醒用户安装该字体后重新打开 |
| 套完封面是 XXX/占位日期 | apply_word_template 没传 cover | 补 cover 字段重套封面部分，或 picks 逐字段修正 |
| 体检 ✗ 但怎么看都对 | 规则理解错位：把 inferred（示范推断）当 required（批注明文） | 回规范书核对原文出处，批注/红字明文优先级高于示范文字观感 |

## 七、验收与交付

1. **硬标准**：论文套模板 = check_paper_format 六节全 ✓ 才算完成；普通格式任务 = 指纹 diff 与目标一致 + 规范逐条 ✓。
2. **三级自检**（§四）按序跑完：内容零改动对比 → 格式指纹对比 → 视觉抽样（可选项，复杂版式/交稿前建议做）。
3. **交付必报**：文件绝对路径 + 改动清单（动了哪些板块/角色）+ "正文文字零改动"声明（格式任务）+ 快照可还原声明 + 目录"更新域"提醒（有目录域时）。
4. 用户不满意：有快照可整体还原，别在崩坏稿上继续缝补，还原后走对应标准链重来。
