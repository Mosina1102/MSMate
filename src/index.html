操作手册与功能说明

连接设备

  • 程序启动后会自动扫描局域网内的设备，左侧"设备"列表会显示发现的设备。
  • 点击设备即可发起连接；首次连接需输入对方显示的配对码（点击顶栏"配对码"查看本机配对码）。
  • 扫不到设备时，可在输入框填写对方 IP 直接连接。
  • 支持同时连接多台设备：新设备连入不会打断当前浏览，点击设备列表中"已连接·切换"可切换浏览的设备；当前设备显示"浏览中"，点击它可断开。
  • 连接断开后会自动重连，无需手动操作。

浏览文件

  • 左侧"我的电脑"面板浏览本机文件，右侧"远程设备"面板浏览对方文件。
  • 根目录下提供 桌面 快捷入口，与 C/D/E 盘同级，可快速进入桌面。
  • 双击文件夹进入，双击本地文件用系统默认程序打开。
  • 顶部"上级"按钮或 ⌫ 键返回上一级。
  • 工具栏可搜索当前目录、按名称/大小/时间排序（默认按修改时间升序，新文件在最下面）。
  • 面板底部状态栏显示当前磁盘的已用/总计/可用空间，方便决策传输大文件。

传输文件

  • 右键文件 → "上传到远程" / "下载到本地"。
  • 拖拽本地文件到右侧远程面板即可上传；拖拽远程文件到左侧本地面板即可下载。
  • 按住 Shift+拖拽 本地文件可拖出到系统桌面/资源管理器。
  • 拖拽远程文件到窗口外（桌面/资源管理器）可直接下载到本机桌面。
  • 支持多选（Ctrl/Shift+点击）后批量上传/下载，支持文件夹递归传输。
  • 传输进度实时显示在左侧"进行中"列表，对方传给你的文件也会显示接收进度。

编辑与新建

  • 远程编辑：右键远程文件 → "远程编辑"，文件会下载到本地用默认程序打开，保存后自动回传。
  • 在空白处右键可新建文件夹、文本文档、Word、Excel、PPT，新建时可先输入文件名。
  • 右键文件 → "重命名 (F2)" 或选中后按 F2 重命名，默认选中文件名部分（不含扩展名），按 Enter 确认、Esc 取消。

复制 / 剪切 / 粘贴

  • Ctrl+C 复制选中文件，Ctrl+X 剪切，Ctrl+V 粘贴到当前目录。
  • 也可右键文件 → "复制/剪切"，在目标目录空白处右键 → "粘贴"。
  • 同设备粘贴=复制/移动文件；跨设备粘贴=上传/下载，剪切=传输完成后删除源文件。
  • 支持远程设备内复制/剪切整理文件，如在远程把文件从一个文件夹移到另一个。

删除与同步

  • 右键文件 → "删除 (Del)"，或选中后按 Del 键删除。
  • 删除对方设备上的文件时，对方会收到通知并自动刷新文件列表。
  • 对方删除你设备上的文件时，本机列表也会自动刷新。

设备备注与改名

  • 点击顶栏本机名称旁的 按钮可修改本机设备名称，改名后对方会同步看到新名称。
  • 右键设备列表中的设备可添加/修改备注，备注仅本机可见，方便区分设备。

快捷键

  • Ctrl+A 全选 · Del 删除 · F2 重命名
  • ⌫ 上级目录 · F5 刷新 · Esc 取消选择
  • Ctrl/Shift+点击 多选 · 右键/拖拽 传输 · Shift+拖出 导出到系统

对讲机

  • 连接设备后，点击右侧远程面板的 「对讲」 按钮并按住不放，即可向对方实时喊话，松开结束。
  • 支持 全局热键（默认 Ctrl+Alt+V），任意单键或组合键均可（如右Ctrl、V、F1，在设置里按下松开即可）；注意单键热键全局生效，打字也会触发。右键「对讲」按钮可自定义。
  • 对方喊话时会自动外放并显示提示条，无需接听。已内置半双工防回声：喊话时自动静音本端接收，外放（不戴耳机）也不会产生回音啸叫。
  • 双端固定 48000Hz 采样率传输，不会因系统音量/设备格式调整出现慢放卡顿。
  • 对讲功能需要双方都升级到支持该功能的版本。

通知

  • 接收/发送文件、远程编辑、新建文件时均有通知。
  • 窗口可见时显示界面提示；最小化到托盘时显示系统通知，点击可打开对应文件。
  • 关闭窗口不会退出程序，而是隐藏到系统托盘继续运行。
